# Third-party notices

FAULTLINES is an original game. No source code, artwork, maps, audio, or names were copied from the projects below. They were read as design references in November 2026. Where a licence would have forced terms onto this project, or where reuse was unclear, the idea was summarised and the material was left alone.

## TripleA

- Project: [triplea-game/triplea](https://github.com/triplea-game/triplea)
- Licence read: GNU GPL-3.0, with a section 7 additional permission for listed libraries.
- Used: nothing.
- Idea kept in our own words: a round is a sequence of country turns; a turn can collect production and then give orders; the AI and the human submit through the same legal orders; the AI can prefer valuable, holdable targets and say what it did.

GPL-3.0 would cover a combined work. None of TripleA's Java, maps, or unit art is included.

## boardgame.io

- Project: [boardgameio/boardgame.io](https://github.com/boardgameio/boardgame.io)
- Licence read: MIT.
- Used: nothing. The library is not installed.
- Idea kept in our own words: a move is a function from state to state; phases can limit which moves exist; an online match should check a seat credential before accepting an order; the server, not the browser, should be the authority.

MIT would have allowed use with attribution. A dependency was not needed for local play, so none was added.

## Freeciv-web

- Project: [freeciv/freeciv-web](https://github.com/freeciv/freeciv-web)
- Licence read: the web client is GNU AGPL-3.0. The C server it wraps is GPL-3.0.
- Used: nothing.
- Idea kept in our own words: a browser can be a view over a rules engine that lives somewhere else, and multiplayer needs a real server process rather than a shared page.

AGPL's network clause would cover a modified client served to other people. None of that client is included.

## OpenFrontIO

- Project: [openfrontio/OpenFrontIO](https://github.com/openfrontio/OpenFrontIO)
- Licence read: code under GNU AGPL-3.0. Repository assets have been under CC BY-SA 4.0, with a separate proprietary set that is not licensed for reuse.
- Used: nothing. No map data, tiles, or sprites.
- Idea kept in our own words: changing an alliance should be visible, and it should change who is a legal target.

The sixteen-theatre rules graph in `js/map.js` is original. It is not traced from OpenFront or OpenStreetMap.

## Open Doctrines

- Project: [Pr1nted/Open-Doctrines](https://github.com/Pr1nted/Open-Doctrines)
- Licence read: OpenDoctrines Non-Commercial License v1.1. Commercial use is reserved, and the README points contributors at a separate agreement.
- Used: nothing. No code, scenarios, portraits, or province data.
- Idea kept in our own words: a grand-strategy campaign can be a set of scenarios, with the interface showing politics and industry that actually change orders.

The non-commercial licence does not clearly allow this project to carry that material, so none of it was copied.

## Natural Earth

- Project: [Natural Earth](https://www.naturalearthdata.com/), 1:10m admin-0 countries, release 5.1.2, via the [nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector) distribution.
- Licence read: public domain. The project asks for a credit, which does not change the licence.
- Used: country outlines in `js/geography.js`, generated by `tools/build-geography.js`.
- Changed: Web Mercator projection, Douglas-Peucker simplification at 0.005 degrees, antimeridian repair, and grouping of countries into the sixteen original theatres. Antarctica and a few sub-antarctic islands are drawn and are not a theatre.
- Credit: Made with Natural Earth. Free vector and raster map data @ naturalearthdata.com.

The raw download is kept out of the repository (`tools/cache/`). The generated file is the asset the game ships.

## Piece models

The forces on the map are original low-poly models built in `js/unit-models.js` and drawn with the browser's WebGL API in `js/piece-layer.js`. Three.js is not installed. There is no external model file, and the pieces do not use letters, emoji, flags, or national insignia. Faction colour is a stripe and a base, not a country badge.

## This edition

Original code, theatre graph, portraits, sigils, unit models, and text. The coastlines are the public-domain Natural Earth data described above. No third-party runtime library is vendored.
